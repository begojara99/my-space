# Welcome to the Gemini CLI

This `GEMINI.md` file serves as a quick guide and central point for interacting with the Gemini CLI within this project.

## How to use Gemini CLI

The Gemini CLI is an interactive assistant designed to help you with various software engineering tasks directly from your terminal. Here are some common ways you can leverage its capabilities:

- **Ask Questions:** Get answers about the codebase, project structure, or specific files.
- **Refactor Code:** Request Gemini to refactor parts of your code for better readability, performance, or adherence to best practices.
- **Fix Bugs:** Describe a bug, and Gemini can help identify and fix it.
- **Implement Features:** Outline a new feature, and Gemini can assist in its implementation.
- **Generate Tests:** Have Gemini create unit or integration tests for your code.
- **Explain Code:** Get explanations for complex functions, classes, or modules.

## Getting Started

To interact with Gemini, simply type your request in the prompt. For example:

- "Explain the purpose of `src/app/page.tsx`"
- "Refactor the `layout.tsx` file to use functional components"
- "Add a new API endpoint to handle user authentication"

## Important Notes:

- Gemini will always prioritize adhering to existing project conventions, style, and structure.
- It will ask for clarification if a request is ambiguous.
- For critical commands that modify your system, Gemini will explain the command's purpose and potential impact before execution.

Feel free to start by asking Gemini a question about this project!
